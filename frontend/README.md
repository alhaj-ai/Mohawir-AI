# منظومة مُحاوِر الذكية (Mohawir AI) — الواجهة الأمامية (Frontend)

واجهة مستخدم تفاعلية متطورة مبنية بأحدث معايير **Next.js 14 (App Router)** و **TypeScript** و **Tailwind CSS v4**، موجهة بالكامل لسوق العمل في الخليج العربي والشرق الأوسط، ومصممة بخط **ثمانية عريض (Thmanyah Bold)** مع اتجاه أصيل من اليمين إلى اليسار (**RTL**).

---

## المزايا البصرية والتقنية (Core Features)

1. **تصميم عربي ملكي (Royal Emerald & Slate)**: لوحة ألوان راقية تعتمد على التدرجات الزمردية وتأثيرات الزجاج الشفاف (Glassmorphism).
2. **الذكاء البصري الطرفي (Edge Vision AI)**: قياس التواصل البصري، تعابير الوجه، ومؤشر الهدوء عبر `face-api.js` و `MediaPipe` محلياً داخل المتصفح دون إرسال الفيديو حفاظاً على الخصوصية 100%.
3. **التحليل الصوتي المزدوج (Dual Audio Intelligence)**: كشف التحدث والتوقف عبر طاقة الصوت (VAD) مع استخلاص كلمات التردد والحشو باللغة العربية عبر `Meyda.js`.
4. **تفريغ صوتي ونطق عربي فائق الجودة**: دعم التعرف المباشر عبر المتصفح `ar-SA` مع النطق الصوتي الطبيعي بواسطة المحركات العصبية (Neural Edge & Google Voices).
5. **لوحة تقييم واستشارة تنفيذية (Executive Scorecard)**: ملخص بيومتري، تحليل إجابات الأسئلة وفق منهجية STAR، وصياغة إجابة بديلة مثالية، مع إمكانية طباعة أو تصدير التقرير PDF.

---

## التشغيل والتطوير (Quick Start)

```bash
# 1. الدخول لمجلد الواجهة
cd frontend

# 2. تثبيت الحزم
npm install

# 3. تشغيل خادم التطوير
npm run dev

# افتح المتصفح على: http://localhost:3000
```
